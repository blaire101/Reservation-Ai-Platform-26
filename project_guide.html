Why use a DM?

The DM converts complex source relationships into one governed, analysis-ready table with stable grain and approved metrics.

DM 把复杂源表关系整理成一张粒度稳定、指标受治理、可直接分析的主题表。
The Agent queries the DM instead of repeatedly joining raw tables. This improves consistency, safety and performance.

Why use a local analytical store?

Local demo

SQLite keeps setup simple and makes automated tests deterministic.

Cloud reference

On AWS, the same analytical layer can map to Athena over Parquet registered in Glue Data Catalog.

Deterministic data-quality controls

Freshness

Is the expected partition available on time?

Completeness

Did the row count fall outside the expected range?

Validity

Are required keys null or duplicated?

The LLM does not calculate these checks. Deterministic Python or SQL tools calculate evidence; the Agent only selects and explains the result.

What is RAG?

Retrieval-Augmented Generation first retrieves relevant enterprise knowledge and then asks the model to answer using that evidence.

RAG 先检索相关企业知识，再让模型基于这些证据生成回答。

📚

LlamaIndex

Knowledge ingestion and retrieval
  • Loads business requirements, metric definitions, table dictionaries and runbooks.
  • Splits documents into retrievable nodes.
  • Adds metadata such as document type, table name and metric name.
  • Builds and queries the vector index.
  • Returns source nodes for evidence-backed answers.
🔗

LangChain

Tools, model interfaces and structured output
In this project, LangChain exposes the knowledge, analytics and quality capabilities as typed tools instead of letting the model access everything directly.
🧭

LangGraph

Explicit state and conditional orchestration
  • Stores the current question, intent, evidence and errors.
  • Routes to Knowledge, Analytics or Quality.
  • Supports retries, fallbacks and evidence validation.
  • Makes the workflow easier to test than an opaque autonomous loop.

90-second project pitch

I built a cloud-portable Reservation Intelligence Data & AI Platform around a simple Reservation-to-Order-to-Payment journey. The structured pipeline integrates campaign, product, reservation and order data into a governed DM at User × Campaign × Product × Site grain. A LlamaIndex knowledge pipeline ingests business requirements, metric definitions, table dictionaries and quality runbooks. LangChain exposes approved knowledge, analytics and quality tools, while LangGraph routes user questions and validates evidence. The project includes deterministic data-quality checks, automated tests, evaluation, Streamlit, FastAPI, Docker and an AWS reference architecture.

我构建了一个云平台无关的预约智能 Data & AI 平台：数据管道生成统一 DM，LlamaIndex 处理企业知识，LangChain 暴露工具，LangGraph 负责路由和证据校验，并包含 DQ、测试、评估、UI、API、Docker 和 AWS 参考架构。

Key architecture decisions

Why combine LangChain, LangGraph and LlamaIndex?
LlamaIndex owns knowledge ingestion and retrieval. LangChain owns tools and structured model interfaces. LangGraph owns state and workflow orchestration.
Why not AutoGen?
Using a second orchestration framework would overlap with LangGraph. The MVP benefits more from explicit state, conditional routing and easier testing.
Why not unrestricted text-to-SQL?
The project uses an approved metric and dimension allow-list, producing a structured query plan and parameterised read-only SQL.
Why keep payment in the order table?
The MVP requires only the final payment outcome. A separate payment-attempt fact table is a future extension when one order can have multiple attempts.

Core interview questions

Why is this an Agent rather than only RAG?

Because it selects among domain tools, maintains state, validates evidence and applies fallbacks.

How do you prevent hallucinated metrics?

The analytics tool accepts only approved metric and dimension names and executes deterministic SQL.

How do you handle late data?

Freshness and completeness checks detect missing partitions; the quality route explains the evidence and recommended action.

How would you migrate to AWS?

Map local files to S3, PySpark to Glue, SQL to Athena, LLM access to Bedrock and containers to ECS Fargate.
